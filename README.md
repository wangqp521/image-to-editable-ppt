# Image to Editable PPT

将幻灯片截图、导出图片或拍摄页面高保真还原为主要文字、数据和基础结构可编辑的 16:9 PPTX。复杂视觉素材保留为局部图片，看不清的内容不会补造。

## 快速调用

```text
使用 $image-to-editable-ppt，把上传的图片还原成可编辑 PPTX；看不清的内容不要猜。
```

## 核心能力

- 将标题、正文、标签和数字重建为可编辑文字，并保留必要的局部样式；
- 将列表、表格、矩阵、合并单元格和基础图形重建为 PowerPoint 原生结构；
- 数据明确时，将常见二维图表重建为带可编辑数据的原生 Chart；
- 将照片、Logo、图标、插画和复杂装饰保留为最小范围的独立图片；
- 支持单页转换和多页按顺序合并；
- 提供结构验证、视觉检查以及字体替代和未验证项说明。

## 验证模式

| 模式 | 特点 | 推荐场景 |
|---|---|---|
| `rapid` | 默认模式，提供基础视觉检查和最多一次集中修复机会 | 日常转换、快速草稿、后续还会人工调整 |
| `reviewed` | 增加更完整的视觉复核和额外修复机会 | 正式交付、高保真要求、需要更严格视觉结论 |

同一批图片使用一种模式；未指定时采用 `rapid`，需要额外视觉审查时请明确指定 `reviewed`。

## 使用方式

### 单页

```text
使用 $image-to-editable-ppt，把上传图片还原成单页可编辑 PPTX，使用 rapid 模式。
优先保持文字、表格和基础图形可编辑；看不清的内容不要补造。
输出文件名为“单页还原_可编辑版.pptx”。
```

### 多页

```text
使用 $image-to-editable-ppt，把上传的 01—08 页图片按顺序还原并合并为可编辑 PPTX。
全部页面使用 reviewed 模式，优先保持文字、表格、流程图和图表可编辑。
看不清的内容不要补造；输出文件名为“项目汇报_可编辑版.pptx”。
```

## 需要提供

- 一张或多张源图片，以及多页任务的正确页序；
- 验证模式和期望的最终文件名；
- 必须优先保持可编辑的内容；
- 可选的原始 Logo、照片、图标、字体、品牌色或版式要求。

建议提供原始分辨率 PNG 或高质量图片；拍摄页面应尽量正对，减少透视、反光、模糊和遮挡。

## 交付内容

- 单页或多页可编辑 `.pptx`；
- 实际生成的页面预览；
- 结构与视觉验证摘要；
- 字体替代、视觉近似和未验证内容说明。

## 能力边界

- 输出为 16:9 PPTX；
- 内容事实正确优先，不美化或补造不可辨认内容；
- 主要文字、数据和基础结构可编辑，不承诺所有视觉素材原生化；
- 低分辨率、模糊、透视、遮挡和缺失字体会影响还原效果；
- rapid 草稿与 reviewed 视觉审查通过版具有不同的验证深度和交付标签。

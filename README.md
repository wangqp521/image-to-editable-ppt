# Image to Editable PPT

把幻灯片截图、导出图片或拍摄页面高保真还原为 16:9 可编辑 PPTX。主要文字、数据和基础结构保持原生可编辑；照片、Logo、图标、插画和复杂装饰保留为最小局部图片。看不清的内容不会补造。

## 快速调用

```text
使用 $image-to-editable-ppt，把上传图片还原成可编辑 PPTX；
使用 rapid 模式，不复用历史产物，看不清的内容不要猜。
```

## 模式

| 模式 | 交付 |
|---|---|
| `rapid` | 默认；以 structure、background、内容完整性和主要可编辑性四项哈希门禁生成可编辑草稿，preview 可选 |
| `reviewed` | 额外要求当前哈希 preview、整页视觉审查、修复后验证和 Final 身份报告 |

同一批图片只使用一种模式。日常转换与后续人工编辑选 rapid；正式高保真结论选 reviewed。

## 输入建议

- 一张或多张原始分辨率图片，以及明确页序；
- 期望的文件名和验证模式；
- 必须优先可编辑的内容；
- 可选的原始 Logo、照片、图标、字体、品牌色或版式要求。

拍摄页面尽量正对，减少透视、反光、模糊和遮挡。

## 交付

- 单页或多页可编辑 `.pptx`；
- 与当前规格/PPTX 哈希绑定的验证摘要；
- 实际成功生成时才提供的 preview/诊断；
- 字体替代、视觉近似、缺页、开放问题和未验证项说明。

rapid 草稿不能称为 reviewed 视觉审查通过版。详细执行与验证合同见 [SKILL.md](./SKILL.md)。
